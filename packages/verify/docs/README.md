# Verify documentation

These files ship inside the npm package at `node_modules/@revyl/verify/docs/`, so a coding agent working in your project can read the docs for the exact version you installed.

| File | Read it when you want to |
| --- | --- |
| [getting-started.md](getting-started.md) | Install Verify, authenticate, and run a first test |
| [writing-tests.md](writing-tests.md) | Learn the test API: `screen`, `expect`, `agent`, `app`, hooks, and steps |
| [configuration.md](configuration.md) | Look up every option in `verify.config.ts` and on the command line |
| [web.md](web.md) | Test a web app in a Revyl cloud browser |
| [mobile.md](mobile.md) | Test an iOS or Android app on a Revyl cloud device |
| [ci.md](ci.md) | Run Verify in GitHub Actions or another CI system |
| [errors.md](errors.md) | Understand an error code and fix it |
| [agents.md](agents.md) | Write and debug Verify tests as a coding agent |

[llms.txt](llms.txt) lists the same files in the llms.txt format.
