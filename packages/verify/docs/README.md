# Verify documentation

These files ship inside the npm package at `node_modules/@revyl/verify/docs/`, so a coding agent working in your project can read the docs for the exact version you installed.

| File | Read it when you want to |
| --- | --- |
| [end-to-end.md](end-to-end.md) | Review live verification scope, observed outcomes, and evidence limits |
| [getting-started.md](getting-started.md) | Install Verify, authenticate, and run a first script |
| [api.md](api.md) | Look up session lifecycle, agent steps, screenshots, commands, files, and processes |
| [configuration.md](configuration.md) | Look up every option in `verify.config.ts`, the environment variables, and the CLI |
| [web.md](web.md) | Open a web app in a Revyl cloud browser, and act on it with exact actions |
| [mobile.md](mobile.md) | Open an iOS or Android app on a Revyl cloud device, and act on it with exact actions |
| [computers.md](computers.md) | Open a Mac computer for commands, files, processes, screenshots, clicks and keys on its screen, and optional recording metadata |
| [ci.md](ci.md) | Call Verify from CI or from a test runner you already use |
| [own-model.md](own-model.md) | Run instructions and validations on your own model, such as Claude, GPT or a local model |
| [errors.md](errors.md) | Understand an error code and fix it, or troubleshoot a common problem |
| [agents.md](agents.md) | Use Verify as a coding agent |
| [guides/check-an-ios-change.md](guides/check-an-ios-change.md) | Have a coding agent check its iOS change on a cloud simulator and share the live link |
| [guides/every-platform.md](guides/every-platform.md) | Run the same checks on iOS, Android and the web at once from one script |
| [guides/session-profiles.md](guides/session-profiles.md) | Start every session signed in with a session profile |
| [guides/playwright-cdp.md](guides/playwright-cdp.md) | Drive a Revyl browser with Playwright over CDP and check it with `validation()` |
| [guides/mac-computer.md](guides/mac-computer.md) | Build, edit files and click macOS apps on a cloud Mac, and get the recording |
| [guides/mac-model-checks.md](guides/mac-model-checks.md) | Check a Mac's screen with `validation()` and `extract()` on its own model |
| [guides/apps-inside-an-inference-mac.md](guides/apps-inside-an-inference-mac.md) | Run an iOS or Web app inside a Mac whose model answers its steps |
| [guides/persistent-computers.md](guides/persistent-computers.md) | Keep a Mac's disk between runs and copy it with snapshots, with use cases |

[llms.txt](llms.txt) lists the same files in the llms.txt format.
