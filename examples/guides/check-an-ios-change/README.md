# Check an iOS change from your coding agent

Opens Settings on a cloud iOS simulator, runs one instruction and one validation, prints the live link and saves `about.png`. Needs Node.js 22.18 or later.

1. `cp .env.example .env` and fill in `REVYL_API_KEY` (or run `npx @revyl/verify login`).
2. `npm install`
3. `npm start`

Guide: https://docs.revyl.com/verify/guides/check-an-ios-change
