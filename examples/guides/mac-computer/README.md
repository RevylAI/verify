# A cloud Mac your agent can drive

Opens a cloud Mac, builds and runs a Swift file, types into TextEdit and clicks a menu by description, then prints the recording's length. Mac computers come with Pro. Needs Node.js 22.18 or later.

1. `cp .env.example .env` and fill in `REVYL_API_KEY` (or run `npx @revyl/verify login`).
2. `npm install`
3. `npm start`

Guide: https://docs.revyl.com/verify/guides/mac-computer
